# Portfolio Watch · IntelInvest 781662

Автономный Android-проект. **Исходники, НЕ собранный и НЕ проверенный APK.**

## Назначение

- Ручное чтение публичного портфеля https://intelinvest.ru/public/portfolio/781662/trades.
- Первая **успешная** проверка сохраняет исходный снимок без уведомлений.
- Повторные проверки выявляют новые/исчезнувшие сделки и изменения строк со стабильным ID.
- Если одинаковые сделки повторяются, сравнение работает как мультимножество, без потери дублей.
- Изменения состава активов учитываются **только когда** опубликованы проверяемые доли активов.
- Изменение рыночной цены и веса позиции само по себе НЕ считается сделкой.
- Локальный журнал с датами, круговая диаграмма и тикеры + названия активов, если они доступны.
- Пользователь задаёт интервал от 15 минут до 7 суток; фоновая проверка WorkManager, без сервера.
- Уведомления только после успешного сравнения. Всё хранится в SQLite на устройстве.

## Важное ограничение интеграции

Получение публичного API IntelInvest для портфеля № 781662 пока **НЕ подтверждено**. На сегодня настраиваемый JS-коллектор извлекает данные из настоящего DOM сайта через WebView. Он отвергает неизвестные/пустые таблицы, видимую пагинацию и виртуализацию. Отдельный экран состава активов на сайте также не был проверен. Если IntelInvest изменил DOM, включил пагинацию или ограничил фоновый WebView, коллектор сообщит об ошибке и **не перепишет** прошлый снимок.

Этот проект нельзя считать подтверждённо функционирующим с реальным портфелем до проверки на Android-устройстве и исправления парсера по фактическому DOM. В коде отсутствуют вымышленные текущие позиции и реальные сделки.

## Сборка

**Для разработчика:** открыть папку в Android Studio, установить Android SDK Platform 35 / Build Tools 35, синхронизировать Gradle и выбрать `Build > Build Bundle(s) / APK(s) > Build APK(s)`. Или через Gradle 8.11.1 выполнить `gradle :app:assembleDebug`.

Также предусмотрен GitHub Actions `.github/workflows/build-apk.yml`: после загрузки в репозиторий и запуска workflow GitHub создаст debug APK как artifact. Облачная сборка — только для сборки исходников; **само приложение не использует сервер**.

Файл `gradle-wrapper.jar` не включён — Gradle устанавливается Android Studio или в CI. Исходные файлы Kotlin/Compose/WorkManager/SQLite включены полностью.

## Проверка, выполненная в этой среде

- `tests/run_tests.sh` — 7 сценариев сравнения операций, все PASS.
- `node --check app/src/main/assets/collector.js` — синтаксис JS корректен.
- Android SDK/Gradle в этой среде отсутствуют, внешние binary downloads недоступны; `assembleDebug` выполнить не удалось.
- APK, Android UI и фактическая загрузка IntelInvest на телефоне **не протестированы**.

## Поведение на телефоне

Первая успешная проверка — базовый снимок. Если сервер пуст, скрывает данные, возвращает только страницу списка либо выдаёт ошибку, не сохранять пустой снимок. Начиная со второго подтверждённого снимка различия добавляются в историю. Фоновое расписание неточное: Android Doze/энергосбережение может откладывать периодические задания. Частота ниже 15 минут не поддерживается без постоянно работающей foreground-service.

## Безопасность

Приложение запрашивает только интернет и разрешение на уведомления, не требует пароля от IntelInvest, не принимает брокерских токенов, не оформляет сделок. Браузер ограничивает навигацию доменами intelinvest.ru. Android backup базы отключён. Данные остаются в локальной SQLite, пока пользователь не удалит приложение.

## Исправления v0.2.0 (14.11.2026)

Загрузка HTML через WebView заменена на прямые публичные JSON-эндпоинты IntelInvest: `/api/public/trades/781662` (все страницы через `offset/limit`) и `/api/public/portfolios/781662/overview` (полный состав с тикерами, официальными названиями и долями). Подтверждены схемы ответов и публичный доступ при браузерной диагностике GitHub Actions. При неполной выдаче, изменении общего числа строк, дублировании ID или сетевой ошибке снимок не сохраняется. Покупки и продажи различаются по `operationLabel`. Сравнение игнорирует колебания котировок. Исправлен контраст заголовка на тёмном фоне. В Actions добавлен реальный сквозной smoke-тест источника перед сборкой APK.

Важно: подпись debug APK может отличаться от предыдущей сборки GitHub Actions. Если Android откажется обновлять установленную v0.1.0, сначала удалите старую тестовую версию. Данные старого приложения при этом удалятся. Приложение пока не проходило теста на физическом Android-устройстве после обновления.


## v0.3.1 — отдельная тестовая установка

Новая версия ставится рядом с предыдущим APK (другой applicationId), чтобы сохранить прежние локальные данные. История автоматически между двумя приложениями не переносится. При запуске версии с рублёвыми суммами первый удачный снимок становится её исходным снимком. Во избежание двойных проверок отключите фоновый режим в прежнем приложении. Подпись debug-сборки GitHub Actions не является постоянной подписью релиза.


## v0.4.0 — результат открытых позиций

Показывает по каждому открытому тикеру рыночную стоимость, долю в портфеле, текущую нереализованную прибыль/убыток в рублях и в процентах. Используются `currCost` и `openPositionInvestedAmount` из публичного API IntelInvest. Поля `profit` и `percProfit` не используются, поскольку содержат исторический реализованный результат. При отсутствии корректной стоимости вложений выводится `—`, а не придуманное значение. Изменения котировок не создают уведомлений о сделках. Для независимой тестовой установки используется пакет `ru.portfolio.watch.rub.openpnl`; прежнее приложение и его данные не удаляются, история между пакетами не переносится.


## v0.5.0 — усиленная фоновая проверка и новый значок

- На главном экране Android: значок с восходящим графиком, отметкой успеха и подписью **Portfolio Watch** (отдельная системная подпись).
- Интервал в минутах (минимум 15): самоперезапускающийся AlarmManager с `setExactAndAllowWhileIdle`, если предоставлено специальное разрешение «Будильники и напоминания»; без него — `setAndAllowWhileIdle`. Пробуждение ставится *перед* сетевой проверкой, чтобы ошибки не прекращали будущие попытки.
- При пробуждении запускается приоритетная задача WorkManager (на Android 12+ `expedited` с мягким переходом на обычную задачу после исчерпания квоты). Периодический WorkManager оставлен как резерв без требования зарядки.
- После перезагрузки/обновления пакета расписание восстанавливается. Приложение показывает время запланированного сигнала, реального пробуждения, запуска, успеха и последней ошибки, а также статус разрешений.
- Через интерфейс можно открыть системный запрос на точные будильники и исключение из оптимизации батареи. Разрешения остаются под контролем пользователя.
- **Ограничение:** Android Doze, ограничение фонового доступа, сетевые сбои, принудительная остановка и квоты приоритетных задач могут задерживать выполнение даже при полном заряде. Нельзя гарантировать строго каждые 15 минут; внешнего сервера по-прежнему нет.
- Тестовая версия устанавливается отдельно с новым идентификатором `ru.portfolio.watch.rub.priority`, сохраняя другие установленные версии и их локальные базы. История между версиями не переносится автоматически; отключите расписание в старых версиях, чтобы не было двойных проверок.
